# Бібліотека компонентів Scroll & Buy для Figma та Звіту (Лабораторна робота №3)

Розробка комплексного модулю **«Бібліотека візуальних компонентів (UI Kit & Figma Export)»**, структурованого за методологією Атомарного дизайну (Атоми $\to$ Молекули $\to$ Організми), з відображенням усіх інтерактивних станів, матрицею правил **Do / Don't**, а також інструментом експорту векторних SVG-елементів та токенів для безпосереднього перенесення у Figma-файл команди на сторінку «03 Компоненти».

## User Review & Critical Decisions

> [!IMPORTANT]
> Відповідно до ваших відповідей на уточнювальні запитання:
> - **Формат отримання**: Готові векторні **SVG-компоненти** (з кнопками швидкого копіювання "Copy SVG" для прямої вставки `Ctrl+V` у Figma та завантаженням файлу) + **JSON-токени** для Figma Variables.
> - **Охоплення**: Усі рівні компонентної системи — **Атоми** (кнопки, інпути, чекбокси, бейджі), **Молекули** (пошук, реакції, слоти розкладу), **Організми** (картка товару, картка-трейд, блок відеострічки, шапка TikTok-профілю).
> - **Документація для звіту**: Візуальні артборди огляду компонентів разом із готовими таблицями варіантів, станів та правил **Do / Don't**, оформленими точно за вимогами розділу 3 методички Лабораторної роботи №3.

## 1. Overview & Core Concept

- **Ціль**: Забезпечити студентам повний набір матеріалів для здачі розділу «3. UI-патерни та елементи дизайн-системи» та сторінки «03 Компоненти» у Figma.
- **Підхід**: Додати до прототипу Scroll & Buy інтерактивний переглядач бібліотеки компонентів із вкладками категорій, візуальним рендерингом кожного стану та панеллю швидкого експорту у Figma (клік $\to$ вставка у Figma векторними об'єктами).

## 3. Таблиці документації Do / Don't (для тексту звіту)

- **Кнопка (Button)**:
  - *Do*: Використовувати дієслова дії в наказовій формі або інфінітиві («Оформити замовлення», «Підтвердити угоду»); забезпечувати контраст не менше 4.5:1.
  - *Don't*: Не ставити дві однакових Primary-кнопки поруч; не використовувати незрозумілі скорочення або "ОК".
- **Картка-трейд (Trade Card)**:
  - *Do*: Завжди відображати статус угоди, фіксовану вартість, код перевірки та кнопки прийняття/відмови.
  - *Don't*: Не дозволяти редагування суми угоди після її підтвердження обома сторонами.
- **Поле вводу (Input Field)**:
  - *Do*: Підсвічувати помилку червоним кольором `#AB3336` разом із пояснювальним текстом під полем.
  - *Don't*: Не покладатися лише на червону рамку без текстового пояснення причини помилки.

## 4. Technical Implementation Steps

1. **Компонент `src/components/FigmaComponentLibraryModal.tsx`**:
   - Інтерактивна модальна сторінка / вітрина UI Kit.
   - Вкладки: «Атоми», «Молекули», «Організми», «Правила Do / Don't», «Експорт у Figma (SVG & JSON)».
   - Кожен компонент має кнопку «📋 Скопіювати SVG», яка поміщає в буфер обміну чистий векторний SVG з правильними розмірами, кольорами та стилями — після чого у Figma достатньо натиснути `Ctrl+V` (Paste), і елемент стає повноцінним векторним шаром!
2. **Файл `src/data/figmaExportData.ts`**:
   - Збережені чисті SVG-шаблони для:
     - Кнопок у всіх 5 станах;
     - Полів вводу у станах Default/Focus/Error;
     - Картки товару Product Card (Variant 2);
     - Картки-трейду Trade Card;
     - Навігаційного бару;
     - Палітри токенів у форматі JSON для імпорту у Figma Variables.
3. **Кнопка відкриття у верхній панелі керування**:
   - Кнопка «📐 UI Kit для Figma» на головній панелі `DeviceFrame` для миттєвого доступу під час захисту.
